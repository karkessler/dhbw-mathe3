1. Definition 2.6.1: Tangentialebene¶

So wie die Tangente im Fall $n = 1$ für die Differenzierbarkeit einer Funktion steht, ist es im Fall $n > 1$ die Tangentialebene. Beide stehen für die lineare Approximation einer Funktion.

Ist $f:D\subseteq\mathbb{R}^m\to\mathbb{R}$ stetig differenzierbar ($f\in C^1(D)$) und $\tilde x\in D$, so heißt die lineare Funktion $$g(x_1,\dots,x_m) = f(\tilde x) + \frac{\partial f}{\partial x_1}(\tilde x)\,(x_1 - \tilde x_1) + \dots + \frac{\partial f}{\partial x_m}(\tilde x)\,(x_m - \tilde x_m) = f(\tilde x) + \nabla f(\tilde x)\cdot(x - \tilde x)$$ die Tangentialebene an $f$ im Punkt $\tilde x$. Für $m = 2$ ist ihr Graph eine Ebene, die die Fläche in $(\tilde x, f(\tilde x))$ berührt.

Interaktiv: Für $f(x,y) = x^2 + y^2$ lässt sich der Berührpunkt verschieben.

2. Beispiel 2.6.2¶

Bestimmen Sie die Tangentialebene von $f(x,y) = x^3y - xy^2 - 8y$ im Punkt $(1,1)$.

$$f_x(x,y) = 3x^2y - y^2\ \Rightarrow\ f_x(1,1) = 2,\qquad f_y(x,y) = x^3 - 2xy - 8\ \Rightarrow\ f_y(1,1) = -9,$$ und $f(1,1) = -8$. Damit lautet die Tangentialebene $$g(x,y) = -8 + 2(x - 1) - 9(y - 1) = -1 + 2x - 9y.$$

3. Definition 2.6.3: Totales Differential¶

Für $f\in C^1(D)$, $x_0\in D$ und jedes $a\in\mathbb{R}^m$ (hier nicht notwendig $\|a\| = 1$) gilt $\frac{\partial f}{\partial a}(x_0) = a\cdot\nabla f(x_0)$. Mit $a_i = dx_i$ (kleine Änderungen) erhält man das vollständige (totale) Differential $$df = f_{x_1}\,dx_1 + f_{x_2}\,dx_2 + \dots + f_{x_m}\,dx_m.$$ Es beschreibt näherungsweise die Änderung von $f$, wenn sich alle Variablen gleichzeitig um $dx_1,\dots,dx_m$ ändern („vollständig“ im Sinne von „gleichzeitig“). Es ist genau der Zuwachs der Tangentialebene: $$f(x_0 + dx)\approx f(x_0) + df.$$

4. Beispiel 2.6.4¶

Für $f(x_1,x_2) = x_1^2 + 3x_1x_2$ an der Stelle $x = (3,2)$: $$f_{x_1} = 2x_1 + 3x_2\ \Rightarrow\ 12,\qquad f_{x_2} = 3x_1\ \Rightarrow\ 9,\qquad df = 12\,dx_1 + 9\,dx_2.$$ Näherung für $f(3.1,\,1.8)$, also $dx_1 = 0.1$, $dx_2 = -0.2$: $$df = 12\cdot 0.1 + 9\cdot(-0.2) = -0.6,\qquad f(3.1,\,1.8)\approx f(3,2) + df = 27 - 0.6 = 26.4.$$ Der exakte Wert ist $f(3.1,\,1.8) = 26.35$.

5. Anwendung: Fehlerfortpflanzung¶

Messgrößen sind fehlerbehaftet. Das totale Differential schätzt ab, wie sich Messfehler $\Delta x_i$ auf ein berechnetes Ergebnis $f(x_1,\dots,x_m)$ auswirken (lineare Fehlerfortpflanzung, Größtfehler): $$|\Delta f|\lesssim\left|\frac{\partial f}{\partial x_1}\right|\,|\Delta x_1| + \dots + \left|\frac{\partial f}{\partial x_m}\right|\,|\Delta x_m|.$$

Beispiel: Ein zylindrischer Tank hat den gemessenen Radius $r = 2\,\text{m}\pm 0.01\,\text{m}$ und die Höhe $h = 5\,\text{m}\pm 0.02\,\text{m}$. Volumen $V = \pi r^2h$: $$dV = 2\pi rh\,dr + \pi r^2\,dh\ \Rightarrow\ |\Delta V|\lesssim 2\pi\cdot 2\cdot 5\cdot 0.01 + \pi\cdot 4\cdot 0.02 = 0.28\pi\approx 0.88\,\text{m}^3.$$ Der relative Fehler ist $\frac{|\Delta V|}{V}\lesssim 2\frac{|\Delta r|}{r} + \frac{|\Delta h|}{h} = 1.4\,\%$: Der Radius geht doppelt ein, weil er quadriert wird. Eine Monte-Carlo-Simulation bestätigt die Größenordnung.
